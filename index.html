PDFs, photos, and Word files. Author names, dates, software stamps, EXIF, and Content Credentials are stripped. Colour profiles stay so the page still looks like itself.

  • The download uses the original filename, ready to put back.
  • Same engine as the desktop tool: ExifTool, then a full rewrite.
